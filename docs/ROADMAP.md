## Фаза 1 — Основна платформа ✅ ЗАВЪРШЕНА

### Картотека (Directory)
- ✅ CRUD за хора (създаване, преглед, редакция, изтриване)
- ✅ Филтриране по град, роля, статус, пол, професия, група
- ✅ Пагинация с избор на размер (15 / 50 / 100 / 500 / 1000)
- ✅ List изглед и Grid изглед
- ✅ Колонна таблица с сортиране
- ✅ Bulk операции (изтриване, промяна статус, добавяне в група)
- ✅ Запазени филтри (Smart Lists) с цветове
- ✅ Inline редакция на полета от профила (EditableField)
- ✅ Excel import (от .xlsx файл)
- ✅ Excel export (избрани хора или всички)
- ✅ CSV export с всички полета
- ✅ Глобално търсене (Ctrl+K) — case-insensitive за кирилица

- ✅ Контакти: телефон (multi-phone), имейл, Facebook, Instagram, LinkedIn, Telegram
- ✅ Адрес: град, адрес, регион, избирателна секция (dropdown с 17 секции)
- ✅ Демография: дата на раждане, пол, ЕГН (уникален, 10 цифри)
- ✅ Образование: университет, специалност, работодател

- ✅ Застъпник (isRepresentative) — toggle
- ✅ Член на СИК (isCommissionMember) — toggle
- ✅ Auto-geocoding при промяна на град (синхронизация с картата)
- ✅ Engagement score (активност)
- ✅ Timeline — обединена хронологична лента (бележки + активности + задачи)
- ✅ Inline редакция в Timeline (Pencil → textarea → save/cancel)
- ✅ Тагове с цветове (inline създаване + търсене)
- ✅ Напомняния
- ✅ Връзки между хора (family, colleague, referral, mentor, neighbor, party)

## Известни проблеми / Технически дълг

| Проблем | Приоритет | Бележка |
|---------|-----------|---------|
| `bulk.ts`, `notes.ts`, `tasks.ts`, `events.ts` не използват ActionResult | Нисък | Работят, но без стандартизирана грешка |
| Telegram интеграция е само линк | Среден | Реалното API изисква bot token |
| Снимки се пазят като URL string | Среден | Нужен е file upload + local storage |
| `activities.ts` inline edit реъхрешира цялата страница | Нисък | Race condition с revalidatePath |
| Campaign модул е само в схемата, без UI | Среден | Фаза 2 приоритет |
